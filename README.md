# json-vazio-csharp-dotnet

Código do vídeo **V036** do canal ForgeTechPit: API devolveu um JSON vazio? O que o C# faz por baixo.

Todo o código roda de verdade no vídeo. Para executar, use o .NET 10 SDK (veja o `global.json`, quando houver) e rode `dotnet test` ou `dotnet run` na pasta do projeto. Os arquivos `saida-*.txt` são as saídas reais mostradas no vídeo.
